# 🎡 Wheel of Fortune (결정 룰렛)

일상적인 선택의 고민을 가볍게 해결해주는 직관적인 웹 룰렛 애플리케이션입니다.

## 🚀 주요 기능
- **다중 입력 지원**: 콤마(,)를 사용해 여러 선택지를 한 번에 쉽게 입력할 수 있습니다. (최대 10개)
- **간편한 공유**: 결과 공유 시 지저분한 URL 파라미터 대신 Firebase Firestore를 활용하여 깔끔하게 결과 링크를 공유할 수 있습니다.
- **자동 배포**: GitHub Actions를 통해 메인 브랜치 머지 시 GitHub Pages로 자동 배포됩니다.

## 🛠 기술 스택
- HTML5, CSS3, Vanilla JavaScript
- Firebase (Firestore)
- GitHub Actions & Pages
